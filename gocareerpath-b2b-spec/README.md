# GoCareerPath B2B Upskilling & Internal Mobility Intelligence Platform - Build Specification

*   **[DATA_PROCESSING_PIPELINE.md](./DATA_PROCESSING_PIPELINE.md)**: Describes the data ingestion, processing, and storage pipeline.
